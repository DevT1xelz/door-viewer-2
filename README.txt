ВХОДНАЯ ДВЕРЬ С БОКОВЫМ ОСТЕКЛЕНИЕМ - САЙТ (three.js) + МОДЕЛЬ ДЛЯ BLENDER
=========================================================================
Дверь сделана по фото-референсу: графитовое полотно с гладкой панелью и 19 вертикальными планками,
длинная ручка-скоба на трёх стойках, боковое остекление (прозрачное с обеих сторон), широкая рама-наличник,
петли справа (ось уходит вглубь, ствол спрятан в зазоре), стена из деревянного сайдинга и бетонная площадка.

ФУРНИТУРА
  Снаружи (сверху вниз): чёрный КВАДРАТНЫЙ замок под большой ключ (ободок, выпуклая накладка,
                          скважина с бородкой), поворотный БАРАШЕК (вращается), замок под МИНИ-ключ (поворачивается),
                          над ними глазок.
  Изнутри:                ручка-рычаг (нажимается при открывании), такой же поворотный барашек, глазок.
                          Панели те же, что снаружи.
  Анимация: отпереть (мини-ключ и барашки поворачиваются, засовы замка втягиваются) - нажать рычаг -
            открыть наружу - закрыть - запереть.

1) САЙТ
   Откройте index.html двойным кликом - сервер и интернет не нужны (всё внутри файла app.js).
   door-standalone.html - то же одним файлом (удобно отправить в мессенджере или почтой).
   Для публикации: загрузите index.html и app.js в одну папку любого статического хостинга.
   Нужен браузер с WebGL2 (Chrome, Safari 15+, Firefox, Edge; ПК и телефоны).

   Управление
     ПК:       левая кнопка мыши - вращать, колесо - приближать, клик по двери - открыть/закрыть.
     Телефон:  один палец - вращать, щипок - приближать, тап по двери - открыть/закрыть.
     Кнопки:   "Открыть дверь", "Снаружи / Изнутри", "Свет: ..." (мягкий свет, ясно, золотой час),
               "Авто-вращение", "i" - характеристики. Фурнитуру можно рассмотреть, приблизив колесом или щипком.

   Графика (качество сохранено)
     - Настоящие HDRI-панорамы (CC0, Poly Haven) + направленное солнце с тенями.
     - MSAA 4x, затемнение в стыках и пазах (GTAO), физическое стекло, карты нормалей, фаски на кромках.

   Оптимизация (чтобы не лагало)
     - Пока вы вращаете или идёт анимация, плотность пикселей снижается (до 1.25 на телефоне, 1.5 на ПК),
       и подстраивается под скорость устройства (вниз до 0.75). Как только движение прекратилось, через долю
       секунды возвращается полное разрешение (до 2.0) - в покое картинка максимально чёткая.
     - Отрисовка только при изменениях: в покое сайт ничего не рисует и не греет телефон.
     - Проход пропускания стекла считается в половинном разрешении, текстуры процедурные и вдвое меньше,
       тени пересчитываются только при движении двери, статичная геометрия склеена по материалам.
     - Проверка скорости: добавьте к адресу ?debug (мс на кадр, FPS, плотность пикселей, вызовы отрисовки).
       ?ao=0 отключает затемнение в стыках (ещё быстрее, если нужно).

2) BLENDER
   blender/door_ribbed.py - та же дверь как скрипт для Blender 4.x / 5.x (проверено на 5.0.1).
   Запуск: Scripting -> Open -> Run Script. Из консоли:
       blender -b -P door_ribbed.py -- --still 1 --view ref --out C:/tmp/door
       blender -b -P door_ribbed.py -- --anim --out C:/tmp/door
   Виды: outside, ref (как на фото), front, inside, handle, handle_in, lock_top, peephole_in, hinge, hinge_front.
   Анимация: 240 кадров. Все размеры и цвета - константы вверху файла. Материалы процедурные.

3) ИСХОДНИКИ САЙТА
   src/main.js - вся сцена (размеры и материалы сверху файла), index.template.html - интерфейс,
   assets/*.hdr - окружения. Пересборка (нужен Node.js 18+):
       npm install
       npm run build        ->  dist/app.js, dist/index.html, dist/door-standalone.html

ЧЕСТНО О ПРЕДЕЛАХ
   - Размеры сняты с фото по пропорциям, это не заводские чертежи. Тыльная сторона и фурнитура внутри придуманы
     (на фото они не видны), как и конструкция барашка и мини-замка.
   - Сайт использует отражения из панорам, а не честную трассировку лучей: по картинке он близок к рендеру
     Blender, но не идентичен ему.
   - Проверено в Chromium (программный WebGL) и Blender 5.0.1; на реальных iPhone/Android не запускалось.
     Цифры скорости на вашем телефоне покажет ?debug.
